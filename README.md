# مزايا التعليم - أكتوبر 2026

نسخة Static مستقلة وجاهزة للنشر على GitHub Pages أو Cloudflare Pages.

## الملفات
- `index.html` الواجهة الرئيسية.
- `styles.css` التنسيق المتجاوب.
- `app.js` البحث والتصنيفات والمفضلة ومعاينة الصفحات.
- `data.js` بيانات الصفحات والنصوص المستخرجة للبحث.
- `assets/mazaya-october-2026.pdf` النشرة الأصلية.
- `assets/pages/` صور معاينات صفحات العروض.

## النشر على GitHub Pages
1. ارفع جميع الملفات والمجلدات كما هي إلى مستودع GitHub.
2. من Settings > Pages اختر Deploy from a branch.
3. اختر فرع `main` والمجلد `/ (root)`.
4. احفظ الإعدادات وانتظر ظهور رابط الموقع.

لا يحتاج المشروع إلى Node.js أو قاعدة بيانات.

## النسخة التفاعلية الجديدة
- المجلد `interactive/` يحتوي نسخة تفاعلية بنفس ألوان وشعارات النشرة (وزارة التعليم، مزايا التعليم، يوم المعلم).
- الرابط بعد تفعيل GitHub Pages: `https://reem2356.github.io/mazaya-education/interactive/`
